Source of truth: repository state as of 2026-09-28. Robinhood Chain facts verified against `docs.robinhood.com/chain`, chain-ID/RPC aggregators (Chainlist, TrustSwap, Dwellir), and Bitquery/DeFiLlama for Lighter. ## Verified external facts (for reference by all rows below)

- **Robinhood Chain**: Arbitrum-Orbit L2 settling to Ethereum. Mainnet chain id **4663** (RPC `https://rpc.mainnet.chain.robinhood.com`, launched 2026-07-01), testnet chain id **46630** (RPC `https://rpc.testnet.chain.robinhood.com`, launched 2026-02-10). Native gas token **ETH**. Explorer: `robinhoodchain.blockscout.com`. Fully permissionless contract deployment (Solidity/Vyper, Foundry/Hardhat unchanged). Public RPCs are rate-limited/not for production — dedicated provider (Alchemy recommended; also QuickNode, Chainstack, Dwellir) needed for real traffic. ERC-4337 account abstraction supported natively. Ecosystem DEXs: Uniswap, Rialto (spot); Lighter, Arcus (perps). Stablecoin: USDG (Paxos "Global Dollar").
- **GMGN**: `gmgn-cli` supports `--chain robinhood` for market discovery, security checks, holder/smart-money data, quotes, swap execution, and condition orders (TP/SL) — condition orders explicitly supported on `robinhood` chain per docs. Robinhood-chain launchpad allow-list includes `trench`, `pons`, and ~24 others (see `GMGN_ROBINHOOD_FIELD_MAP.md`).
- **Lighter**: dedicated Robinhood-chain instance ("ZkLighter"), a zk-rollup contract on Robinhood Chain. Margin currency is **USDG** (6 decimals, not ETH), locked into Lighter's Robinhood-chain contract. Matching engine/order book/positions/funding/liquidations run **inside the zk rollup**, not as individual Robinhood Chain transactions — only deposits, pending withdrawals, and batch-commit/verify/execute events are on-chain-visible. Off-chain state requires Lighter's own API/WS, not generic RPC reads.
